# OMNIFACTORY — Финансовый центр клиента

Новый read-only раздел `/account/finance` использует существующую базу счётов и проверенных платёжных записей клиента. **Он не создаёт платежи и не активирует платные услуги.**

## Правила подсчёта

- Счета: отбор по `Invoice.created_at` внутри выбранного календарного месяца; для каждого отображаются сумма и фактический статус. Сумма выставленных счетов ≠ выручка.
- Ожидают оплаты: сумма документов `Invoice.status == 'pending'` в выбранном месяце.
- Подтверждённые поступления: только `PaymentRecord.status == 'confirmed'` и `verified_at IS NOT NULL`, с `verified_at` внутри выбранного месяца. Данные выбираются только по `org_id` авторизованного клиента.
- Разные валюты не складываются друг с другом, суммы считаются в целочисленных минимальных единицах и отображаются с двумя десятичными знаками.
- CSV содержит исходные целочисленные суммы `amount_minor` для точного импорта; защищён от инъекций формул в названиях, провайдерах и ID. Это реестр внутренних записей, не фискальный документ и не банковская выписка.
- Фильтр принимает `YYYY-MM`, год 2000–2100; отчёты не принимают диапазон произвольного размера.

## Приёмка

```powershell
.\.venv-omni\Scripts\python.exe -m ruff check .
.\.venv-omni\Scripts\python.exe -m pytest -q tests/test_client_finance_center.py
.\.venv-omni\Scripts\python.exe -m pytest -q
```

Открыть `/account/finance?period=2026-11`, проверить карточки и CSV; повторить под второй организацией. Неподтверждённые платёжные строки не должны отображаться и учитываться. Без выполненного теста с авторизованным настоящим провайдером нельзя утверждать, что онлайн-эквайринг работает.
