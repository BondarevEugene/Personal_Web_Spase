# OMNIFACTORY Client Identity & Security Center

## Завершённые пользовательские сценарии

**А. Регистрация/вход на выбранном языке.**
Открыть `/account/register?lang=uk` или `/account/login?lang=en`. Выбранный язык сохраняется в скрытом поле формы и в настройках нового аккаунта. Для существующего клиента предпочтение в БД важнее языка формы входа. URL не влияет на другое лицо.

**Б. Смена пароля и прекращение всех ранее открытых сессий.**
Открыть `/account/security`, указать текущий пароль и новый (12–128 символов), повторить его. Сервер проверяет Argon2id и CSRF, не допускает прежний пароль, обновляет хеш в одной транзакции, удаляет **все** существовавшие сессии клиента и выдаёт только одну новую сессию на текущем устройстве. Данные заказов, организация, настройки языка и роли не изменяются.

**В. Завершить сеансы на других устройствах.**
Форма требует текущий пароль и CSRF, удаляет только прочие DB-backed сессии текущего пользователя, оставляет текущую сессию и сессии других клиентов.

**Г. Выйти со всех устройств.**
Текущий пароль и CSRF обязательны, удаляются все сессии только данного клиента; браузер очищает cookie и переходит к форме входа. Без нового входа API кабинета должен возвращать перенаправление или отказ.

## Приватность и ограничения

- Сеансы представлены по дате создания без сырого токена и без IP/геолокации. Хранимый в БД токен — только SHA-256 hash.
- Ни одна форма не сохраняет пароль в браузерном хранилище проекта, истории событий или транзакционных таблицах.
- Нет публичного self-service reset по email, подтверждения email, TOTP/2FA или passkeys. Не выдавать экран за полноценную MFA-платформу.
- В этом PR не меняются колонки БД, схема Alembic, биллинг или контракты Graph Studio.
- В инфраструктуре для продакшена требуется HTTPS; сессия и CSRF уже ограничены соответствующими cookie-политиками. Защита от distributed brute-force потребует Redis/WAF rate limits.

## Приёмка

```powershell
.\.venv-omni\Scripts\python.exe -m ruff check .
.\.venv-omni\Scripts\python.exe -m pytest -q tests/test_account_security_center.py tests/test_client_workspace_i18n.py tests/test_client_workspace_unified.py
.\.venv-omni\Scripts\python.exe -m pytest -q
```

Проверить два независимых браузера одного пользователя и третий браузер другой организации. При смене пароля первая сессия получает новый cookie, вторая автоматически теряет доступ; третья не меняется. Проверить UA/RU/EN на страницах регистрации, кабинета и защиты аккаунта, а также отсутствие секретов в HTML. Тесты и CI должны быть зелёными до слияния.
