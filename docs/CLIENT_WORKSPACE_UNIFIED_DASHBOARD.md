# OMNIFACTORY Client Workspace — Unified Dashboard

## Цель
Клиент должен видеть, что требует действий, и быстро переходить в уже работающие разделы. Не заменяем бизнес-логику декоративными панелями.

## Реализовано
- Единая сквозная навигация на главной, в заказах, карточке заказа, уведомлениях, сервис-деске, финансах и тарифах (включая страницы отдельных обращений).
- Состояние активной вкладки определяется из текущего URL; нет отдельной JS-навигации, ненадёжных client-side роутеров или фальшивых переходов.
- Три главных приоритета, построенных из SQL и ограниченных текущей организацией: **проекты на приёмке**, **проекты с истёкшим сроком**, **персональные непрочитанные уведомления**.
- Вверху сдержанная компактная рабочая зона; сохранены существующие операционные формы, кнопки и маршруты Graph Studio/Automation Studio.
- CSS вынесен в `omni_site/static/client_workspace.css`, работает без JS, поддерживает узкий экран и `prefers-reduced-motion`.

## Что намеренно не меняем
- Оплата остаётся подтверждаемой только в серверном биллинге. Декоративных выручек или оплаченных счетов нет.
- Черновики конструкторов **не называются опубликованными ботами**.
- Клиентская изоляция выполняется на уровне SQL; панель не запрашивает данные другой организации.
- Этот PR не создаёт новые сущности или миграции, не меняет публикацию проектов и не затрагивает авторизацию.

## Проверки
```powershell
.\.venv-omni\Scripts\python.exe -m ruff check .
.\.venv-omni\Scripts\python.exe -m pytest -q tests/test_client_workspace_unified.py
.\.venv-omni\Scripts\python.exe -m pytest -q
```

Проверить в двух организациях с разными заказами: приёмка, просрочка, уведомления, корректное открытие клиентских страниц. Дополнительно — узкий мобильный экран (навигация прокручивается по горизонтали), клавиатура, реальные формы, контраст. На страницах ввода пароля используем прежние отдельные auth-шаблоны.

## Остаётся после этого релиза
Глубокая UX-приёмка реальными клиентами, последовательная локализация UA/RU/EN, единая модель доступа к инструментам и запуск опубликованных ботов на сервере.
