CORE ACTIVE

USED_TECHNOLOGIES

CORE_FUNCTIONS

  • Асинхронный расчет матриц: Мгновенное вычисление нумерологических карт, психоматриц Александрова и жизненных циклов без блокировки основного потока API.
  • Динамический генератор отчетов: Потоковое формирование структурированных аналитических данных на основе персональных параметров.
  • Интегрированный API контракт: Полная совместимость с экосистемой OmniFactory для оркестрации и вызова расчетных модулей внешними ботами.

SYSTEM_FEATURES

  • Изоляция контекстов: Использование строго типизированных схем Pydantic для полной валидации входных данных на лету.
  • Модульная масштабируемость: Расчетные алгоритмы вынесены в обособленный движок (`engine.registry`), что позволяет подключать новые типы матриц за секунды.
  • Высокая отказоустойчивость: Асинхронный Lifespan-цикл с защитой от утечек памяти при фоновом сборе телеметрии ядра[cite: 3].
